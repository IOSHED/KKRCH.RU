### <span style="background:#42A5F5;padding:5px">POST</span> `/support/tickets/{ticket_id:uuid}/reopen`

|                | Описание                                                                |
|----------------|-------------------------------------------------------------------------|
| **Назначение** | Пользователь переоткрывает закрытый тикет, пока действует окно TTL      |
| **Логика**     | 1. Ownership; `now < closed_at + 7 days`.                               |
|                | 2. Можно reopen **многократно** в этом окне (лимита «1 раз» нет).       |
|                | 3. `status=awaiting_admin`; уведомить бота (текст последнего контекста).|

После истечения 7 дней — только новый тикет.

---

| Kind                     | Код | Описание              |
|--------------------------|-----|-----------------------|
|                          | 200 | Переоткрыт            |
| auth_error               | 401 | Не авторизован        |
| ticket_not_found_error   | 404 | Нет доступа           |
| reopen_not_allowed_error | 409 | Окно TTL истекло      |
| server_error             | 500 | Ошибка                |
