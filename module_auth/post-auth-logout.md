### <span style="background:#42A5F5;padding:5px">POST</span> `/auth/logout`

|                | Описание                                                                                |
|----------------|-----------------------------------------------------------------------------------------|
| **Назначение** | Выход из текущей сессии                                                                 |
| **Логика**     | 1. Валидирует access_token.                                                             |
|                | 2. Отзывает текущую сессию пользователя в Postgres (`revocation_reason = user_logout`). |
|                | 3. Удаляет access_token из Redis.                                                       |
|                | 4. Если передан refresh_token — инвалирует его также (удаляет из Redis).                |
|                | 5. Возвращает сообщение об успехе. Операция идемпотентна.                               |

---

| Kind         | Код | Описание                          |
|--------------|-----|-----------------------------------|
|              | 200 | Успешный выход                    |
| auth_error   | 401 | Нет или некорректный access token |
| server_error | 500 | Внутренняя ошибка сервера         |

---

<summary><b>Пример запроса</b></summary>

```json

  "refresh_token": "a1b2c3d4-e5f6-7890-abcd-ef1234567890"
}
```
