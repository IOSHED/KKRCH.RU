### <span style="background:#EF5350;padding:5px">DELETE</span> `/auth/sessions/{session_id}`

|                | Описание                                                                                              |
|----------------|-------------------------------------------------------------------------------------------------------|
| **Назначение** | Отзыв конкретной пользовательской сессии                                                              |
| **Логика**     | 1. По переданному session_id ищет сессию пользователя, убеждается в её принадлежности и актуальности. |
|                | 2. Отзывает сессию в Postgres (`revocation_reason = user_logout`).                                    |
|                | 3. Удаляет связанный refresh_token из Redis.                                                          |
|                | 4. Если это текущая сессия — удаляет также access_token.                                              |
|                | 5. Возвращает результат.                                                                              |

---

| Kind                    | Код | Описание                           |
|-------------------------|-----|------------------------------------|
|                         | 200 | Сессия успешно отозвана            |
| auth_error              | 401 | Нет или некорректный access token  |
| session_not_found_error | 404 | Сессия не найдена или уже отозвана |
| server_error            | 500 | Внутренняя ошибка сервера          |
