### <span style="background:#42A5F5;padding:5px">POST</span> `/auth/logout_all`

|                | Описание                                                                                                      |
|----------------|---------------------------------------------------------------------------------------------------------------|
| **Назначение** | Выход из всех сессий пользователя                                                                             |
| **Логика**     | 1. Валидирует access_token.                                                                                   |
|                | 2. Все активные сессии пользователя в Postgres помечаются как отозванные (`revocation_reason = user_logout`). |
|                | 3. Все refresh-токены пользователя удаляются из Redis.                                                        |
|                | 4. Текущий access_token также удаляется из Redis.                                                             |
|                | 5. Возвращает сообщение и количество закрытых сессий.                                                         |

--- 

| Kind         | Код | Описание                          |
|--------------|-----|-----------------------------------|
|              | 200 | Отключение всех сессий            |
| auth_error   | 401 | Нет или некорректный access token |
| server_error | 500 | Внутренняя ошибка сервера         |

---

<details open>
<summary><b>Пример ответа</b></summary>

```json
{
  "revoked_sessions": 5
}
```

</details>
