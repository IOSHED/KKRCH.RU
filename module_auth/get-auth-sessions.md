### <span style="background:#7CB342;padding:5px">GET</span> `/auth/sessions`

|                | Описание                                                                                           |
|----------------|----------------------------------------------------------------------------------------------------|
| **Назначение** | Список всех активных (не revoked, не expired) сессий пользователя                                  |
| **Логика**     | 1. Валидирует access_token в заголовке `Authorization`.                                            |
|                | 2. По user_id ищет все сессии пользователя, которые не отозваны и не истекли (таблица `sessions`). |
|                | 3. Для каждой сессии добавляет информацию о user_agent, ip, времени создания, истечения.           |
|                | 4. Определяет `is_current` для сессии, с которой пришёл запрос.                                    |
|                | 5. Возвращает массив сессий.                                                                       |

---

| Kind         | Код | Описание                          |
|--------------|-----|-----------------------------------|
|              | 200 | Список сессий                     |
| auth_error   | 401 | Нет или некорректный access token |
| server_error | 500 | Внутренняя ошибка сервера         |

---

<details open>
<summary><b>Пример ответа</b></summary>

```json
{
  "sessions": [
    {
      "session_id": "uuid",
      "user_agent": "Mozilla/5.0 ...",
      "ip": "192.168.1.1",

      "expires_at": "2025-02-15T10:00:00Z",
      "is_current": true
    }
  ]
}
```
