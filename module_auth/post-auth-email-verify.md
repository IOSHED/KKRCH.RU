### <span style="background:#42A5F5;padding:5px">POST</span> `/auth/email/verify`

|                | Описание |
|----------------|----------|
| **Назначение** | Войти по коду из письма. Тот же email, что у Яндекса, Google или VK, — тот же пользователь |
| **Логика**     | 1. Код — 6 цифр. Сверяется хеш и число попыток. |
|                | 2. Найти или создать пользователя, привязать провайдер `email`. |
|                | 3. Выдать сессию. `200` — аккаунт уже был, `201` — создан сейчас. У нового аккаунта `users.locale` = `Accept-Language` запроса. |
| **Заголовки**  | `User-Agent`, `X-Fingerprint` (опционально) |

---

| Kind               | Код | Описание |
|--------------------|-----|----------|
|                    | 200 | Вход в существующий аккаунт |
|                    | 201 | Новый аккаунт |
| validation_error   | 400 | Email или код не из 6 цифр |
| invalid_login_code | 400 | Код неверный, истёк или кончились попытки |
| server_error       | 500 | Внутренняя ошибка |

Тело `200`/`201` совпадает с [`POST /auth/oauth_login`](post-auth-oauth_login.md).
